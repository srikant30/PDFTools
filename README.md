# PDFTools

A lightweight browser-based PDF utility suite built using pure HTML, CSS, and JavaScript.

No backend server, database, or file upload required.  All PDF processing happens locally in the user's browser for maximum privacy and speed.

---

# Features

## PDF Operations
- Merge Multiple PDFs
- Split PDF Pages
- Compress PDFs
- Add Watermark to PDFs
- Password Protect PDFs

## Conversion Utilities
- PDF to JPG
- PDF to Excel

---
